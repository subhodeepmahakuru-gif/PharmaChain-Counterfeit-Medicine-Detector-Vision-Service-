1. Project OverviewRole: Build the "eyes" of PharmaChain—an image classifier that inspects medicine packaging photos to determine whether they are genuine or counterfeit.   Integration: Member 2's /verify-image endpoint calls this service, and Member 5's portal uses its photo tab. If a pack is classified as counterfeit with a confidence $\ge 0.7$, Member 2's API triggers a blockchain update (set()) to flag the batch as compromised.   2. Technologies UsedLanguage & Core Libraries: Python 3.10+, PyTorch, torchvision, Pillow, scikit-learn.   Backend & API: Flask, requests.   Architecture: ResNet-18 (transfer learning using ImageNet pretrained weights).   Environment: CPU laptop (or Google Colab with a GPU for larger datasets).   3. System WorkflowPlaintext[Photo Uploaded] --> [Member 5 Portal] --> [Member 2 API (/verify-image)] 
                                                    │
                                                    ▼
[Blockchain Batch: COMPROMISED] <── (Confidence >= 0.7) ── [Member 4 ML Service (Port 5001)]
Input: A photo of a medicine pack is uploaded via Member 5’s portal.   API Call: Member 2's backend sends a POST request with the image to Member 4's service ([http://127.0.0.1:5001/predict](http://127.0.0.1:5001/predict)).   Classification: The ResNet-18 model evaluates the image and returns a JSON response containing the label (genuine or counterfeit), confidence score, and class probabilities (scores).   Action: If the label is counterfeit and the confidence is $\ge 0.7$, Member 2's API updates the blockchain state for that batch to COMPROMISED.   4. Main Filesrequirements.txt: Lists dependencies (torch, torchvision, pillow, numpy, scikit-learn, flask, requests).   make_demo_data.py (Option A): Generates a synthetic dataset of fake and genuine medicine boxes using code to quickly prove the pipeline works.   make_counterfeits.py (Option B): Takes real genuine packaging photos and programmatically applies realistic defects (blurs, fades, tints, covered patches, shear, JPEG damage, noise) to build a robust training dataset while splitting files by source photo to prevent leakage.   train.py: Handles ResNet-18 transfer learning, applies custom augmentations (omitting horizontal flips and color jitter to preserve text/color clues), saves the best validation model to model.pt, and outputs metrics.json.   predict.py: A command-line script that loads model.pt and classifies a single photo.   ml_service.py: A Flask API running on port 5001 providing health check (/health) and prediction (/predict) endpoints.   test_service.py: Tests the local ML service and verifies the full end-to-end pathway through Member 2's API and the blockchain.   5. Important Notes & LimitationsData Leakage Prevention: make_counterfeits.py splits source photos into train/val/test splits before generating variants, ensuring a base photo never overlaps across splits.   Augmentation Restrictions: Training augmentations intentionally exclude horizontal flips and color jitters, as mirrored text and shifted colors are primary indicators of counterfeits.   Report Limitations to State:Synthesized counterfeits mean the model learns specific artificial defects rather than all real-world variants.   Small datasets from limited brands restrict overall generalization.   Softmax confidence is a design threshold ($0.7$) rather than a calibrated true probability.   9.
